# czip-auto — أرشفة الجلسات المُضغوطة تلقائيًا

إضافة Hermes بروفايلية: تحزم المحادثات المكتملة في أرشيف مضغوط (LZMA) وتمنح النموذج أدوات
استرجاع دقيقة (`czip_map` / `czip_search` / `czip_range`) بدل الاعتماد على الملخص فقط.
بعد الحزم، تُحقن جملة توجيه في سياق الضغط (`pre_compress` hook) تخبر النموذج أن النص الكامل
مؤرشف وأين يجده.

> ملاحظة: هذا تنفيذ محلي مستقل بتنسيق `CZAP1` خاص بها؛ لا علاقة له بحزمة `czip` الخارجية.

## البنية

| الملف | الدور |
|---|---|
| `__init__.py` | تسجيل الإضافة: 3 أدوات + `pre_compress` hook + skill (أوامر `/czip-auto`) |
| `packer.py` | التسجيل في `state.db`، البوابة، كتابة الحزم، الفهرس، سياسة الاحتفاظ، الاسترجاع |
| `skill/SKILL.md` | سلوك الوكيل مع الأرشيف + الأوامر اليدوية `/czip-auto pack/prune/status` |

## الحزمة والفهرس

- تنسيق `CZAP1`: سجل لكل رسالة (دور، نص، طابع زمني)، مضغوط LZMA.
- `index.json` متزامن مع القرص؛ عناوين الفهرس تُبني من محتوى الحزمة نفسها.
- كتابة ذرية: ملف مؤقت ثم `os.replace`. الملفات اليتيمة تُكنس.

## البوابة (متى تُحزم الجلسة؟)

تُفحص في خيط خلفي بعد انتهاء الدورة، وكل الشروط لازمة:

| الشرط | الافتراضي | ملاحظة |
|---|---|---|
| عدد الرسائل | `min_messages: 200` | |
| حجم النص | `min_bytes: 512000` | |
| الفوز المتوقع | `min_compression_gain: 2.0` | النسبة الموزونة للبايتات؛ يمنع أرشفة ما لا يستحق |
| التهدئة | `cooldown_seconds: 3600` | بين حزمتين لنفس الجلسة |
| النمو | `min_growth_messages: 50` | رسائل جديدة بعد آخر حزمة |
| المصدر | جلسات وليدة الواجهة فقط | انظر التخطي |

## سياسة التخطي

لا تُحزم الجلسات ذات `source=subagent` (موجز الاستخدام، محتواها يدمج في الأب)،
كذلك `cron`/`gateway_hygiene` (خدمية عابرة) — إلا بتفعيل صريح في الإعداد (`allow_cron` إلخ).

## سياسة الاحتفاظ (تعمل بعد كل حزمة)

| الحد | الافتراضي | سلوك 0 |
|---|---|---|
| `max_packs` | 50 | يعطل الحد |
| `max_age_days` | 30 | يعطل الحد |
| `max_total_bytes` | 200MB | يعطل الحد |

الأقدم يُحذف أولًا، وأحدث حزمة **لا تُحذف أبدًا** حتى لو تجاوزت الميزانية وحدها.
الملفات اليتيمة (بلا مدخل فهرس) تُكنس.

## العزل

الإضافة تعمل فقط في البروفايلات التي تذكرها في `plugins.enabled` (نوع standalone).
الأدوات مؤجلة خلف جسر `tool_search` — كلفة الـ schema ≈ صفر لكل نداء API.
`state.db` يُفتح **قراءة فقط**؛ كل كتاباتها في `session-packs/` داخل HOME البروفايل.
لا تكتب في أي قاعدة بيانات Hermes (state/shared/kanban/projects/stats).

## الإعداد (config.yaml للبروفايل)

```yaml
plugins:
  enabled:
    - czip-auto
  czip-auto:
    min_messages: 200
    min_bytes: 512000
    cooldown_seconds: 3600
    min_growth_messages: 50
    min_compression_gain: 2.0
    max_packs: 50
    max_age_days: 30
    max_total_bytes: 209715200   # 200MB بالبايت
```
